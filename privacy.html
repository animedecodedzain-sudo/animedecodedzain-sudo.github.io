Privacy policy

Anime Decoded Uploader is a personal tool used only by the owner of the Anime Decoded YouTube channel.

  • It accesses only the owner's own YouTube channel, to upload videos, set publish times, thumbnails and playlists, and read the channel's own video list.
  • The sign-in token is stored only on the owner's own computer. No data is sent to any other server, sold or shared.
  • No data from any other Google user is collected.
  • Access can be removed at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
